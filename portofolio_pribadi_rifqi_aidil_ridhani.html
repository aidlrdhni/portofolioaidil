Tentang Saya

Ringkasan latar belakang pendidikan dan pendekatan kerja dalam mempelajari pengembangan perangkat lunak di tingkat sekolah menengah kejuruan.

Membangun Dasar Pengembangan Web yang Terstruktur

Saya adalah Rifqi Aidil Ridhani, siswa kelas XI pada kompetensi keahlian Pengembangan Perangkat Lunak dan Gim (PPLG) di SMKN 2 Banjarmasin. Selama menempuh pembelajaran kejuruan, saya mendalami fundamental pembuatan halaman web menggunakan HTML5, CSS3, dan JavaScript secara bertahap dan terukur.

Saya meyakini bahwa aplikasi web yang baik tidak hanya bergantung pada logika program yang akurat, tetapi juga pada tata letak visual yang tenang, mudah dipahami pengguna, serta kemampuan komunikasi dan kolaborasi yang solid bersama rekan tim selama pengerjaan proyek.

Kompetensi & Keterampilan

Keahlian

Perpaduan kemampuan teknis dasar pengembangan web dan keterampilan interpersonal. Klik kartu keahlian untuk melihat catatan penerapan praktisnya.

Teknis

HTML5 Dasar

Menyusun kerangka dokumen web semantik, navigasi terstruktur, dan elemen antarmuka yang rapi serta mudah diakses.

Catatan penerapan praktis +
Diterapkan untuk membangun struktur semantik halaman portofolio, tampilan panel jam digital, dan tata letak kontrol dashboard yang terorganisir.
Teknis

CSS3 Dasar

Mengatur tata letak responsif menggunakan Flexbox dan CSS Grid, variabel warna tema, serta proporsi jarak yang seimbang.

Catatan penerapan praktis +
Digunakan untuk merancang sistem tema Terang & Gelap yang nyaman di mata serta memastikan tampilan beradaptasi mulus di layar ponsel maupun laptop.
Teknis

JavaScript Dasar

Manipulasi DOM interaktif, pengelolaan logika waktu real-time, penanganan event pengguna, dan penyimpanan lokal.

Catatan penerapan praktis +
Diterapkan pada pembaruan detik secara real-time di aplikasi Jam Digital, logika pengaturan timer pada dashboard, serta penyimpanan preferensi mode gelap.
Teknis

Desain UI Dasar

Merancang tata letak antarmuka minimalis dengan hierarki tipografi yang jelas, keterbacaan tinggi, dan navigasi intuitif.

Catatan penerapan praktis +
Mengutamakan kesederhanaan visual dan pemilihan kontras warna yang tidak melelahkan mata sehingga informasi utama mudah dipindai pengguna.
Soft Skills

Komunikasi

Menyampaikan ide rancangan secara runtut, mendengarkan masukan dengan terbuka, dan mempresentasikan hasil karya dengan jelas.

Catatan penerapan praktis +
Terlatih saat memaparkan alur kerja aplikasi dan fitur antarmuka di hadapan guru serta teman sekelas pada kegiatan praktik di SMKN 2 Banjarmasin.
Soft Skills

Kerja Tim

Berkolaborasi dalam kelompok praktikum PPLG dengan pembagian tugas yang terkoordinasi dan tanggung jawab bersama.

Catatan penerapan praktis +
Bekerja sama dalam menyelaraskan struktur kode, tata letak tampilan, dan pengujian fungsi aplikasi bersama rekan kelompok belajar.
